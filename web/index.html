使用前

  1. 任一人粘贴华为云临时 docker login 并登录（服务器共享；不确定时点「检查登录」）
  2. 勾选一个或多个微服务、选分支，点「构建所选」（也可点单行「构建并推送」）
  3. 可同时跑多个任务（含同一微服务）；达到并发上限前不必排队。运行中可点「停止任务」强制停掉。多服务同一次任务归档到同一目录
